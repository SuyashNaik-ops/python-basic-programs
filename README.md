 python-basic-programs
Basic Python programs for beginners — conditionals, recursion, strings, and Fibonacci.
A collection of basic Python programs designed for beginners to practice and strengthen their programming fundamentals. This repository covers essential Python concepts such as variables, data types, operators, conditional statements, loops, functions, recursion, strings, lists, tuples, sets, dictionaries, and basic-problem-solving.

It also includes commonly practiced programs such as Fibonacci series, prime numbers, palindrome checking, factorial, number patterns, string manipulation, searching, and other beginner-friendly exercises.

The goal of this repository is to build a strong foundation in Python programming and improve logical thinking step by step.
